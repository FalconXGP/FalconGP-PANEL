🚀 About FalconGP

FalconGP is a powerful, modern and feature-rich Minecraft hosting control panel built with Node.js.

Manage your Minecraft servers, users, resources, files and server configurations through a beautiful, responsive web interface designed for hosting providers, server owners and gaming communities.

From server management to live console monitoring and dynamic configuration, FalconGP brings essential hosting tools together in one control room.

«AnosCloud™ — Powered By FalconGP»

✨ Features

🎮 Minecraft Server Management

- Create and manage Minecraft servers.
- Start, Stop and Restart servers.
- Live server status monitoring.
- Real-time console output.
- Send commands directly to your server.
- Support for popular Minecraft server software.
- Server uptime and statistics.

📊 Resource Management

- RAM allocation.

📦 Installation

Requirements

- Node.js 20 or newer
- npm
- Java Runtime Environment (for Minecraft servers)
- Git

1. Clone the Repository

git clone https://github.com/FalconXGP/FalconGP-PANEL.git
cd FalconGP-PANEL

2. Install Dependencies

npm install

3. Configure the Panel

Configure your database, panel settings and environment variables as required.

4. Start FalconGP

npm start

Development Mode

npm run dev

«Full Installation Tutorial: See "TUTORIAL.md" (TUTORIAL.md) for complete setup instructions.»

«Make sure the commands above match the scripts defined in your "package.json".»

🔐 Security

For production deployments:

- Use strong admin passwords.
- Keep Node.js and dependencies updated.
- Use HTTPS.
- Protect database files.
- Configure proper user permissions.
- Never expose private credentials.
- Run Minecraft servers with appropriate system permissions.
- Keep regular backups of important data.
